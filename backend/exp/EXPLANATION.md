# شرح كود الواجهة الخلفية (Backend) لمشروع معالجة صور الأشعة السينية

هذا المستند يشرح بالتفصيل كود ملف `main.py` والملفات المساعدة المرتبطة به، موضحاً سبب استخدام المكتبات، وظائف الدوال، والمدخلات والمخرجات.

---

## 1. المكتبات المستخدمة وسبب استخدامها

| المكتبة | سبب الاستخدام |
| :--- | :--- |
| **FastAPI** | إطار عمل (Framework) حديث وسريع جداً لبناء الـ APIs. تم اختياره لسهولته ودعمه للعمليات غير المتزامنة (Asynchronous). |
| **Uvicorn** | خادم (Server) لتشغيل تطبيق FastAPI. |
| **OpenCV (cv2)** | المكتبة الرائدة في معالجة الصور (Digital Image Processing). تُستخدم هنا لعمليات التنعيم، التباين، اكتشاف الحواف، وغيرها. |
| **NumPy** | تُستخدم للتعامل مع الصور كمصفوفات رقمية (Arrays)، مما يسهل إجراء العمليات الحسابية عليها (مثل الجمع والطرح والمتوسط). |
| **PyTorch** | إطار عمل للذكاء الاصطناعي، يُستخدم هنا لتحميل وتشغيل نموذج التنبؤ بالجنس من خلال صور الأشعة. |
| **Timm** | مكتبة تحتوي على نماذج رؤية حاسوبية جاهزة (Pre-trained Models). استخدمنا منها نموذج `EfficientNet-B4`. |
| **Pillow (PIL)** | لمعالجة الصور الأساسية وتحويلها إلى تنسيقات متوافقة مع نموذج الذكاء الاصطناعي. |

## 2. شرح ملف `main.py` (سطر بسطر)

### الاستيرادات (Imports)
- **الأسطر 1-3:** استيراد المكونات الأساسية من `fastapi` مثل `File` و `UploadFile` لاستقبال الصور، و `HTTPException` للتعامل مع الأخطاء.
- **السطر 4:** `uvicorn` لتشغيل التطبيق.
- **السطر 6:** استيراد `get_classifier` من `model_utils.py` للحصول على نموذج التنبؤ.
- **السطر 7:** استيراد عمليات معالجة الصور من `image_processing.py` تحت اسم مختصر `dip`.

### إعداد التطبيق (App Setup)
- **السطر 9:** إنشاء كائن التطبيق `app`.
- **السطر 11-17:** إعداد **CORS (Cross-Origin Resource Sharing)**. هذا ضروري جداً للسماح للموقع (Frontend) بالتواصل مع الـ API حتى لو كانا على منافذ (Ports) مختلفة.

### نقاط النهاية (Endpoints)

#### 1. التنبؤ بالجنس (`/predict`)
- **الهدف:** استقبال صورة أشعة والرد بنتيجة التنبؤ (ذكر/أنثى).
- **المدخلات:** ملف صورة (`UploadFile`).
- **المخرجات:** كائن JSON يحتوي على (الجنس، نسبة التأكد، رقم الفئة).
- **آلية العمل:** يتم قراءة الصورة كبايتات (Bytes)، ثم تمريرها لنموذج الذكاء الاصطناعي الذي يقوم بتحليلها وإرجاع النتيجة.

#### 2. معالجة الصور (مجموعة `/process/`)
تستخدم هذه المسارات مكتبة `OpenCV` و `NumPy` عبر الملف المساعد `image_processing.py`:

- **المتوسط (`/process/average`):** تأخذ قائمة صور وتدمجها لتقليل التشويش.
- **الطرح (`/process/subtract`):** تأخذ صورتين وتطرحهما لإظهار الاختلافات (مثلاً قبل وبعد صبغة).
- **تصحيح الإضاءة (`/process/shading-correction`):** تستخدم صورة "تظليل" لتصحيح توزيع الإضاءة غير المتساوي في الصورة الأصلية.
- **التحجيم/القناع (`/process/mask`):** تطبيق قناع (Mask) لإظهار جزء معين فقط من الصورة.
- **إضافة التشويش (`/process/add-noise`):** إضافة أنواع مختلفة من Noise (Gaussian, Salt & Pepper) لأغراض الاختبار.
- **التنعيم (`/process/smooth`):** تطبيق فلاتر مثل Gaussian أو Median لتقليل الحدة والتشويش.
- **زيادة التباين (`/process/enhance-contrast`):** استخدام تقنية CLAHE لتحسين وضوح التفاصيل في صور الأشعة الباهتة.
- **اكتشاف الحواف (`/process/detect-edges`):** استخدام خوارزمية Canny لإظهار حدود العظام أو الأعضاء.

## 3. شرح الملفات المساعدة

### أ- ملف `image_processing.py`
يحتوي على الدوال الحسابية الفعلية:
- **`bytes_to_numpy`**: تحول البيانات الخام القادمة من المتصفح إلى مصفوفة يفهمها `OpenCV`.
- **`numpy_to_bytes`**: تحول الصورة بعد معالجتها إلى تنسيق PNG ليتم إرسالها مجدداً للمتصفح.
- **الدوال المعالجة**: تستخدم دوال `cv2` (مثل `cv2.GaussianBlur`, `cv2.Canny`, `cv2.equalizeHist`) لتنفيذ المهام المطلوبة.

### ب- ملف `model_utils.py`
يتحكم في نموذج الذكاء الاصطناعي:
- **`XrayGenderClassifier`**: كلاس (Class) يقوم بتحميل نموذج `EfficientNet-B4` المحفوظ في ملف `.pth`.
- **`transform`**: دالة تقوم بتجهيز الصورة (تغيير الحجم لـ 384x384، تحويلها لـ Tensors، وتطبيع الألوان) لتكون مطابقة لما تدرب عليه النموذج.
- **`predict`**: تقوم بتمرير الصورة عبر الشبكة العصبية واستخراج النتيجة النهائية باستخدام دالة `softmax` لحساب الاحتمالات.

## 4. ملخص آلية العمل
1. يرسل المستخدم صورة عبر واجهة React.
2. يستقبل `FastAPI` الطلب في `main.py`.
3. إذا كان الطلب معالجة (DIP)، يتم استخدام `OpenCV`.
4. إذا كان الطلب تنبؤ (Prediction)، يتم استخدام `PyTorch`.
5. يتم إرجاع النتيجة (سواء كانت صورة معالجة أو نص JSON) إلى المستخدم.
